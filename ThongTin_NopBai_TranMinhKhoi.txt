3. CÁC CHỨC NĂNG
---------------------------------------------------------------------
Chú thích: [API xong] = backend C# đã viết xong | [App] = giao diện Flutter
(Cột [App] ghi lại đúng thực tế khi nộp: đánh dấu X nếu đã làm xong và chạy được)

1) Đăng ký tài khoản qua email (OTP xác thực email)
   [API xong]  POST /api/Auth/register, /verify-email, /resend-otp     [App: X ]
2) Đăng nhập: tên đăng nhập + mật khẩu + OTP email
   [API xong]  POST /api/Auth/login, /verify-otp (trả JWT, role)       [App: X ]
3) Phân quyền: Admin -> trang quản trị; Quản lý -> trang quản lý; Nhân viên -> Dashboard nhân viên
   [API xong]  JWT có claim role + trường redirect                      [App: X ]
4) CRUD
   - Phòng ban                [API xong]  /api/PhongBan                 [App: X ]
   - Ca làm việc              [API xong]  /api/CaLamViec                [App: X ]
   - Vị trí chấm công + QR    [API xong]  /api/ViTriChamCong            [App: X ]
   - Nhân viên                [API xong]  /api/NhanVien                 [App: X ]
   - Bảng chấm công           [API xong]  /api/ChamCong                 [App: X ]
   - Đơn nghỉ phép + duyệt    [API xong]  /api/DonNghiPhep              [App: X ]
   - Quản lý tài khoản/vai trò[API xong]  /api/TaiKhoan                 [App: X ]
   - Dashboard thống kê       [API xong]  /api/ThongKe                  [App: X ]
5) 3 chức năng thuyết trình (chọn 3/6)
   a) Chia sẻ vị trí (chấm công GPS, giới hạn bán kính)  [API xong]  [App: X ]
   b) Quét QR động (đổi mỗi 60 giây)                     [API xong]  [App: X ]
   c) Đăng nhập/chấm công bằng khuôn mặt                 [API xong - so khớp vector]  [App: X ]
6) Tính năng mới tự đề xuất: chống gian lận chấm công + Điểm chuyên cần
   - Ràng buộc thiết bị, chặn vị trí giả lập, đánh dấu bản ghi nghi vấn
   - Điểm chuyên cần 0-100, xếp loại, chuỗi ngày đúng giờ, bảng xếp hạng
   [API xong]  [App: X ]
7) Giao diện đẹp, dễ dùng, cả nhóm chạy được
   [App: X ]  (đã có file README hướng dẫn chạy, .env mẫu, tài khoản mẫu)
